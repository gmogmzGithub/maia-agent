# Record entitlements as append-only history, without billing

What a Brokerage Organization may do will be recorded per capability as
append-only rows carrying a state, an optional numeric ceiling, a source
(package, tier, add-on or override), a written reason and an author; a change
supersedes rather than edits. A capability with no recorded entitlement is
refused, not permitted, so adding a capability never silently grants it to
existing customers and "we sold this" stays distinct from "nobody has decided".
The packaging shape — a base package, tiers by Advisor seats, optional integration
add-ons, measurable WhatsApp and model usage — exists as structure only: nothing
is priced, no invoice is produced and no money moves, because charging is a
separate commercial decision that has not been authorised. Usage is recomputed per
calendar month rather than incremented, for the reason the analytics projection
already gives.
