# Treat organic discovery as a publication contract

Every Published Listing has one stable, descriptive, canonical Larevia URL whose
initial HTML contains its essential authorized facts, page metadata, semantic
heading structure, primary image information, and JSON-LD consistent with what a
customer can see. The site may use server rendering or static generation; a
client-only shell that requires successful JavaScript execution to expose the
Listing is not an acceptable publication surface.

Product remains the catalog authority. It automatically generates canonical
sitemaps from the listings actually eligible for publication and makes
availability, authority, update time, price visibility, media, and removal state
coherent across the visible page, structured data, and crawler response. A
withdrawn URL redirects only to a genuinely equivalent replacement; otherwise it
returns an honest unavailable experience and the appropriate HTTP/indexing state.

The public site is optimized for people first and for both traditional and
generative search through the same useful, current, well-linked information. The
MVP does not create thin location permutations, keyword pages, duplicated
EasyBroker descriptions, hidden crawler-only content, or a separate `GEO` content
system. `llms.txt` is not a required authority surface and may be evaluated only
as a non-authoritative complement if current provider support justifies it.

Crawler permissions are explicit policy. Search retrieval, user-requested page
access, and model-training collection are not assumed to be the same purpose.
Before launch, the operation verifies current official provider documentation,
the actual `robots.txt`, perimeter rules, rendered HTML, sitemaps, and indexing
behavior. No promise of first position or assistant inclusion is made.

At launch, verified crawlers needed for search retrieval are allowed while
training-only crawlers are blocked until the Organization makes an explicit legal
and commercial decision. EasyBroker query access does not authorize public
indexing; only Listings with current publication and media authority receive a
canonical Larevia page.

Initial local editorial pages cover Guadalajara, Zapopan, and Tlaquepaque.
Neighborhood guides are published only when supported by real inventory, demand,
and verified local expertise, never as automatically generated keyword or price
permutations. A withdrawn Listing initially retains an honest unavailable page
with authorized alternatives; it redirects only to a genuinely equivalent
replacement and otherwise leaves the index through the appropriate HTTP and
indexing state.

Search Console, local business presence, and minimal first-party conversion events
measure discovery through appointment confirmation. Measurement excludes
keystroke capture, mouse trails, session replay, and advertising profiles; the
essential Saved Collection cookie remains separate from optional analytics.
The business-level success measure is verified Property Visit Appointments with
an unpaid Opportunity Origin; rankings, impressions, clicks, assistant citations,
and intermediate interactions remain diagnostic measures.
