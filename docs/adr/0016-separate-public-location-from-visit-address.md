# Separate Public Location from the private Visit Address

Property Documents and the public Property Catalog contain only the Public Location
approved for ordinary customer conversations. An optional exact Visit Address is
private operational data held outside the public repository and is released only
after a booking is confirmed; it may then be used in the private Calendar event and
Telegram administration. This prevents Hermes from exposing a visit destination
prematurely while preserving the information needed to carry out confirmed visits.
