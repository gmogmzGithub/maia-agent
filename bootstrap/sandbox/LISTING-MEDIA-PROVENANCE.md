# Sandbox Listing Media Bootstrap Photography

These photographs are import inputs for Maia's explicit local Sandbox bootstrap.
The bootstrap submits them through Product's real Listing Media lifecycle into
private S3-compatible object storage; neither Product nor Site serves files from
this directory after import.

The Unsplash photographs were selected by Guillermo Gomez and downloaded on
2026-08-29. The repository copies are resized JPEG derivatives. Unsplash's
license was reviewed on 2026-08-29; it permits commercial and non-commercial
use and does not require attribution, while prohibiting sale of unmodified
images and compilations that reproduce an image service. See
<https://unsplash.com/license>.

These files are not evidence of a real property, address, availability, price,
or brokerage relationship. The local seed records that synthetic provenance
and authority evidence in PostgreSQL for every Listing Media row.
